Sistema operativo:
Es el programa principal que permite que el computador o servidor funcione.
Administra los recursos necesarios para ejecutar aplicaciones.

Node.js:
Es la herramienta que permite ejecutar código JavaScript fuera del navegador.
Se utiliza para crear servidores y aplicaciones.

Aplicación server.js:
Es el archivo donde está escrito el código del servidor.
Define las rutas y las respuestas que recibe el usuario.

Puerto:
Es un punto de comunicación donde el servidor recibe solicitudes.
En esta actividad usamos el puerto 3000.

Logs:
Son registros que muestran información sobre lo que ocurre en un sistema.
Ayudan a detectar errores y revisar el funcionamiento.
