El login es el proceso que permite a una persona ingresar a una aplicación utilizando un usuario y una contraseña. Esto ayuda a saber quién está usando el sistema. Algunas funciones deben estar protegidas para evitar que cualquier persona pueda modificarlas o ver información privada. También es importante cuidar los datos de los usuarios para proteger su privacidad. Nunca se deben mostrar contraseñas, documentos de identidad, teléfonos, direcciones ni otra información personal. De esta manera la plataforma es más segura y confiable para todos.
